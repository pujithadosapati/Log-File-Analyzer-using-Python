## Log File Analyzer using Python
## Project Description
The Log File Analyzer is a Python-based project that reads server log files and analyzes web server activities.
It identifies total requests, error responses, frequently used IP addresses, and the most requested endpoints.
## Objectives
- Analyze server log files.
- Count total HTTP requests.
- Identify error responses.
- Find frequently occurring IP addresses.
- Identify popular endpoints.
## Technologies Used
- Python
- Collections (Counter)
- Regular Expressions
- File Handling
## Features
1. Total request counting.
2. Error response identification.
3. Top IP address analysis.
4. Most requested endpoint identification.
5. Malformed log line handling.
## Python Concepts Used
- File Handling
- Dictionaries and Counter
- Loops and Conditional Statements
- String Processing
- Regular Expressions
## Sample Output
- Total Requests: 7
- Total Error Responses: 2
- Malformed Lines: 1
- Top IP Address: 192.168.1.10
- Most Requested Endpoint: /home
## Applications
- Web server monitoring
- Network traffic analysis
- Error detection
- Website performance monitoring
## Conclusion
This project helped me understand Python file handling, data analysis, collections, and string processing through a practical server log analysis application.
